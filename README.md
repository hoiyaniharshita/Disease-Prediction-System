# Disease Prediction System

This project uses machine learning algorithms to predict diseases based on patient symptoms.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- SQLite

## Features
- Data preprocessing and feature engineering
- Model training using Naive Bayes and Decision Tree
- Model evaluation using precision, recall and F1-score
- Disease prediction with ~84% accuracy

## Dataset
Patient symptom dataset containing 300+ records.

## How to Run
1. Install required libraries
2. Run the main Python script
3. Input symptoms to get disease prediction
